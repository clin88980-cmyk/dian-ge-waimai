# 点个外卖吧

一个外卖点餐场景的交互原型。核心想法：在你点到高热量那一单时，
助手会告诉你具体数字，再找几个口味接近的给你看 —— 换不换都可以。

## 在线体验

开启 GitHub Pages 后访问：`https://<用户名>.github.io/dian-ge-waimai/`

## 包含什么

- 14 家店 / 84 道菜 / 12 个品类，含真实菜品配图
- 高热量提醒与相似菜替换
- 饭搭子投票（两票支持才下单）
- 圈子：5 个话题、评论、打卡
- 地图选址（腾讯位置服务，按需加载，不可用时降级为地址列表）
- 热量预算计算（Mifflin-St Jeor，带安全下限提示）

## 文件说明

- `index.html` — 完整原型，单文件自包含，直接用浏览器打开即可
- `API接入技术方案.md` — 外卖平台与地图服务的真实接入路径分析
